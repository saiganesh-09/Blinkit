# 🛒 Blinkit Grocery Sales Dashboard

An interactive sales analytics dashboard built on Blinkit's grocery dataset with 8,500+ real transactions.

## 🔍 Key Insights
- Tier 3 cities generated the highest sales volume despite fewer outlets
- Fruits & Vegetables and Snack Foods are the top-performing categories
- Medium-sized outlets outperform larger ones in average order value

## ⚙️ Features
- Live filters — outlet type, location tier, category, fat content & year
- Dynamic charts that update in real time
- Business Insights section with auto-computed KPIs

## 🛠 Tech Stack
HTML · CSS · JavaScript · Chart.js
